## 先弄清楚：VPS 的每个参数到底管什么

一句话版本：CPU 管处理能力，内存管同时能跑多少东西，硬盘管存多少和读写快慢，月流量是每月的数据额度，带宽是端口速度，机房和线路决定你访问它的速度。

**内存（RAM）**是最该优先保证的一项。Linux 系统、Web 环境、数据库、面板全部吃内存，程序开得越多要得越多；内存不够时网站变慢，严重时部分服务会被系统直接关掉。

**CPU** 负责处理任务。网站访问、数据库查询、压缩文件、跑脚本都占 CPU，普通博客和低流量网站的要求通常不高，程序和动态请求多了压力才慢慢上来。

**硬盘**现在基本只看 SSD——固态盘读写速度普遍在 500MB/s 以上，机械盘只有 100MB/s 左右。容量上，够放系统、网站文件和备份就行，不用追求大。

**流量和带宽是两回事**。月流量（比如 2TB/月）是每月能用掉的数据总量，带宽（比如 1Gbps）是端口速度。普通网站对端口速度的要求其实很低，从 1Gbps 升到 2.5Gbps，网页打开速度也不会有明显变化，因为网页速度更多取决于线路、延迟、丢包和服务器负载。理想指标可以记两个数：延迟 50ms 以内，丢包率 1% 以内。

## 内存怎么选：1GB 是建站的硬门槛

只跑一个轻量网站，1GB 能用；装面板、WordPress、数据库再加几个插件，2GB 才宽松；一台机器放多个网站或者同时跑几个服务，从 4GB 起步。512MB 属于“理论能装”，实际建站别考虑。

这个门槛是软件版本定的。LNMP 一键包的官方要求写得很清楚：装 MySQL 5.6/5.7 必须 1GB 以上内存，装 PHP 7 也必须 1GB 以上；用 MySQL 5.7 或 MariaDB 10 的话，硬盘至少留 9GB。宝塔面板标称 512MB 最低能装、推荐 768MB 以上，面板自身常驻约 60MB 内存。而主流 CMS（WordPress 这类）现在推荐的 MySQL 5.6+ 和 PHP 7.3+ 组合，512MB 内存根本不够看。

所以预算有限的时候，先保证内存够用，比盲目堆 CPU 核心更值。内存不足的代价很直接：网站变慢，严重的直接被系统杀掉进程。

## CPU、硬盘和流量：别为用不到的东西付钱

普通用途 1-2 核够用，硬盘 20GB 起步，流量按最大用量留出余量选档。这三项最常见的毛病是买大了。

CPU 这边要知道一件事：核心数只是一个参数。同样标 2 核，不同处理器、宿主机负载和商家的资源分配方式，都会让实际性能差出一截，所以没必要只拿核心数量去对比两台 VPS。买之前还要看一眼商家对 CPU 的限制政策——有的商家管得很严，网站突然爆火、访问量暴增时可能被限速甚至暂停，到那时只能升级套餐。

硬盘按内容类型估。纯文字博客 20GB 用不完；图片、附件、压缩包和本地备份多的站，空间消耗快得多，日志和数据库还会持续膨胀，留足余量。

流量的估算逻辑很简单：访客打开网页、加载图片、下载文件都消耗流量。普通博客和小网站一个月几百 GB 往往用不掉；图床、下载站、经常传大文件的用途才是流量大户，选套餐时重点核对月额度。现在主流套餐的端口带宽动辄 1Gbps 起步，对网页访问来说已经严重过剩，预算该花在流量额度和线路质量上。

## 下单后先验机：三步测试别省

拿到机器第一件事是测试，发现问题立刻退款或换机，别先把环境搭完——这是低价 VPS 最容易吃亏的地方。

1. **测连通性**：本地 `ping 你的服务器IP`。ping 不通，大概率是 IP 被墙——海外商家的 IP 池里总有些被用坏的段位，运气差就会碰上。发现异常第一时间找客服处理。
2. **测硬件**：在服务器上跑 `wget -qO- bench.sh | bash`，一条命令看完系统信息、网络带宽和硬盘读写速率，顺便和购买页宣传的指标核对。别以为大厂就不缩水：腾讯轻量香港 24 元档的实测记录显示，带宽能跑满 30Mbps，但标称 SSD 的硬盘连续读写只有 100 多 MB/s，实际是机械盘的水平。
3. **测路由**：本地 `tracert 服务器IP` 看去程，服务器上用 `mtr 你的公网IP -r` 看回程。路由结果只能做参考，同一台机器不同人的访问速度可能截然不同，你自己的晚高峰体验才算数；也不必迷信优质线路，CN2 GIA 这类线路的差价可能成倍，普通线路未必不够用。

## VPS 配置选择的几个高频问题

**512MB 内存还能买吗？**
跑静态页或极轻量的代理勉强可以，建站不行——MySQL 5.6+ 和 PHP 7 的 1GB 门槛摆在那里。

**1 核够用吗？**
个人博客、代理、测试环境都够。并发和动态请求上来后再升级，多数商家支持在线升级，选购时给配置留 30% 余量比较稳妥。

**月流量 2TB 是什么概念？**
纯文字博客哪怕每天几百个访问量，一个月也很难用掉 100GB；图床和下载站才是流量大户，按单文件大小乘以预估下载次数粗算，再往上留余量。

**机房怎么选？**
按访客所在地区选，物理距离近延迟通常更低。但国内访问海外 VPS 还受运营商和线路影响，距离近不等于快，下单前看看机房的测速数据和晚高峰表现更靠谱。
